# AC-03 指标计算

- **ID / 版本**：AC-03 / 1.0.0
- **粒度**：原子能力
- **归属注意力**：分析师（指标口径定义）＋ 数据（源字段口径）

---

## 1. 职责

按一份显式的指标定义，从数据集计算派生指标与聚合，产出「维度 × 指标」结果表，
并**回显每个指标的口径与公式**，保证计算可解释、可追溯。

**不做**：不渲染图表（交 AC-05）、不做数据清洗/去重（交 AC-01/02）、不猜测口径。

---

## 2. 输入契约

### 2.1 数据集
标准信封（见规范 §4）。参与计算的字段须为数值或可聚合类型。

### 2.2 指标定义 `metrics_def`
```json
{
  "dimensions": ["分组维度字段"],
  "filters": [ { "field": "", "op": "eq|ne|gt|gte|lt|lte|in|contains", "value": null } ],
  "metrics": [
    { "name": "指标名",
      "agg": "sum|count|count_distinct|avg|median|min|max|ratio",
      "field": "被聚合字段（count 可空）",
      "numerator": null, "denominator": null,
      "caliber": "口径说明：统计范围、单位、与业务定义的对应" }
  ]
}
```
- `agg=ratio` 时用 `numerator`/`denominator`（可引用其它指标名或字段表达式）。
- `caliber`（口径）**必填**——无口径的指标不予计算，判 `failed`。这是刻意约束：防止口径黑箱。

---

## 3. 参数 `params`

| 参数 | 取值 | 默认 | 说明 |
|------|------|------|------|
| `null_policy` | `skip` / `as_zero` / `fail` | `skip` | 聚合时遇空值的处理 |
| `div_zero` | `null` / `zero` / `fail` | `null` | ratio 分母为 0 的结果取值 |
| `round` | int / null | `null` | 结果保留小数位（null 不处理） |
| `with_overall` | bool | `false` | 是否额外输出不分组的总计行 |

---

## 4. 输出契约

```json
{
  "metric_table": {
    "schema": [ {"name":"维度/指标名","type":"","desc":""} ],
    "rows": [ { "维度字段": "值", "指标名": 数值 } ],
    "meta": {...}
  },
  "metric_manifest": [
    { "name": "指标名", "agg": "", "field": "", "caliber": "口径回显",
      "formula": "实际执行的计算表达式", "null_policy": "", "div_zero": "" } ]
}
```
- `metric_manifest` 把每个指标「怎么算的」显式写出，与结果表一一对应，供分析师与验收核对。

**回执 `deltas`**：`{ "input_rows": 行数, "metrics": 指标数, "groups": 分组数, "div_zero_hits": 命中次数 }`，
`status`：正常 `success`；缺口径/字段不可聚合 `failed`；`div_zero=fail` 或 `null_policy=fail` 命中 `failed`。

---

## 5. 错误与边界

| 情况 | 处理 | status |
|------|------|--------|
| 指标缺 `caliber` | 中止 | failed |
| 被聚合字段非数值且 agg 需要数值 | 中止 | failed |
| ratio 分母为 0 且 `div_zero=fail` | 中止 | failed |
| 空值且 `null_policy=fail` | 中止 | failed |
| 分组维度字段不存在 | 中止 | failed |
| filters 过滤后无数据 | 返回空表 | partial |

不负责：异常值识别、口径正确性判断（口径由分析师定义，本能力只忠实执行并回显）。

---

## 6. 幂等与确定性

纯函数：同数据集 + 同指标定义 + 同参数 ⇒ 同结果表与 manifest。`median` 等需定义稳定排序以保证确定性。

---

## 7. 复用场景

- **CM-03 指标出图组合**第一步。
- 营销复盘 Topic：各渠道曝光/互动/转化率计算。
- 艺人全维评估 Topic：多维度打分聚合。
- 电商销量 Topic：久谦数据的价量、份额、同比。

---

## 8. 验收标准

- [ ] 各 `agg` 类型对样例产出正确数值（含 count_distinct、median、ratio）。
- [ ] 缺 `caliber` 的指标被拒绝（failed），不产出半成品结果。
- [ ] `div_zero` 三种策略分别得到 null / 0 / failed。
- [ ] `null_policy` 三种策略结果符合定义。
- [ ] `metric_manifest` 的 `formula` 与结果可被人工复算对上。
- [ ] 回执 `deltas.metrics` = 指标数。
