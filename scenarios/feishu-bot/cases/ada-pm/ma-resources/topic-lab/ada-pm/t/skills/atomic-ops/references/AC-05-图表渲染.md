# AC-05 图表渲染

- **ID / 版本**：AC-05 / 1.0.0
- **粒度**：原子能力
- **归属注意力**：产品（表达规范）＋ 研发（渲染可靠性）

---

## 1. 职责

按一份显式的图表定义，把数据集/指标表渲染为图表产物（图片 / HTML / 图表规格 JSON），
并产出图表元数据。

**不做**：不计算指标（交 AC-03，本能力只消费已算好的表）、不做数据清洗、不保存产物到持久存储
（落盘交 AC-06，本能力只产出产物对象/临时句柄）。

---

## 2. 输入契约

### 2.1 数据集
标准信封（见规范 §4），通常是 AC-03 的 `metric_table`。

### 2.2 图表定义 `chart_def`
```json
{
  "type": "line | bar | stacked_bar | pie | scatter | area | table",
  "encodings": {
    "x": "字段名", "y": "字段名或字段数组",
    "series": "分组字段（可空）",
    "label": "数据标签字段（可空）" },
  "title": "图标题",
  "axis": { "x_title": "", "y_title": "", "y_format": "number|percent|currency" },
  "sort": { "by": "字段", "order": "asc|desc" },
  "limit": null
}
```
- `encodings` 引用字段必须存在于数据集 schema，否则判 `failed`。
- 图类型与编码的匹配约束见 §5（如 pie 不接受多 y）。

---

## 3. 参数 `params`

| 参数 | 取值 | 默认 | 说明 |
|------|------|------|------|
| `format` | `png` / `svg` / `html` / `vega` | `png` | 产物格式；`vega` 仅输出规格 JSON 不栅格化 |
| `theme` | `blueai` / `default` | `blueai` | 主题/配色；默认走公司 blueai 主题 |
| `width` | int | `960` | 像素宽 |
| `height` | int | `540` | 像素高 |
| `locale` | `zh-CN` / `en` | `zh-CN` | 数字/日期本地化 |

---

## 4. 输出契约

```json
{
  "artifact": {
    "format": "png|svg|html|vega",
    "content_ref": "临时句柄或内联内容（png/svg 为临时路径，vega 为内联 JSON）",
    "bytes": 0 },
  "chart_meta": {
    "type": "", "title": "",
    "encodings_resolved": { "x": "", "y": [], "series": "" },
    "data_rows": 0, "theme": "", "dimensions": "960x540" }
}
```
- 产物是**临时**的；持久化与可检索 id 由 AC-06 负责。本能力只保证产物可被 AC-06 消费。

**回执 `deltas`**：`{ "charts": 1, "data_rows": 行数, "type": "图类型", "format": "" }`，
`status`：正常 `success`；编码字段缺失/类型不匹配 `failed`；数据为空仍可出空图框架 `partial`。

---

## 5. 错误与边界

| 情况 | 处理 | status |
|------|------|--------|
| 编码引用字段不在 schema | 中止 | failed |
| pie/scatter 等类型给了不兼容编码（如 pie 多 y） | 中止 | failed |
| `y_format=percent` 但字段非数值 | 中止 | failed |
| 数据为空 | 出带标题的空图 | partial |
| `limit` 截断数据 | 完成并在 meta 标注截断 | partial |

不负责：指标计算、口径解释、产物归档。

---

## 6. 幂等与确定性

同数据 + 同定义 + 同参数 ⇒ 同图表规格（`vega`/`svg` 可逐字节一致）。
`png` 栅格化可能受渲染引擎版本影响，确定性以 `vega`/`chart_meta` 为准。

---

## 7. 复用场景

- **CM-03 指标出图组合**第二步。
- 所有需要可视化交付的 Topic：营销复盘趋势图、电商价量图、舆情声量曲线。
- 与飞书导出入口衔接：`html`/`png` 产物供报告嵌入。

---

## 8. 验收标准

- [ ] 各 `type` 对样例数据产出结构正确的产物（`vega` 规格可校验）。
- [ ] 编码字段缺失时判 `failed`，不产出坏图。
- [ ] 不兼容的类型/编码组合被拒绝。
- [ ] `theme=blueai` 应用公司配色；切 `default` 可对比差异。
- [ ] `y_format=percent/currency` 的坐标与标签按 `locale` 正确格式化。
- [ ] 回执 `chart_meta.data_rows` = 输入行数（未截断时）。
