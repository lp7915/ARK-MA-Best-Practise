# 启动、资源挂载与恢复

名称：启动、资源挂载与恢复
适用范围：MA中PM及所需子智能体；本包合成业务场景
版本：1.2.0
负责人：Ada 项目维护方（模拟岗位；正式责任人待业务方指定）
状态：MA集群Demo运行规则；尚待真实平台构建与验收。

## 装配
PM 唯一入口，t/g/s/validator 为同一员工内一层子智能体；所有工作由 PM 分派与回收，子智能体不创建后代，h 是人工。共享输出是能力而非另一个岗位。
按 agents 清单显式挂载 Skill/工具/知识，未声明即不挂载。运行环境一份，所有角色共用。启动核对实例使用类型、项目背景、补充要求、真实入口、材料范围和输出目标；预算配置可保留，本轮不作为自动门槛。
## 版本
本资源包首次完整交付不提供 change-set。建议业务线 ID topic-lab、员工 ID ada-pm 均等待平台确认，不声称全局注册成功。资源包、运行、产物、验证和交付不同对象不混存。
恢复从平台实际保留的task、run、Context、产物摘要和未决点核对，不能只靠上一会话临时文件。事件 ID 相同内容只处理一次，不同内容拒绝覆盖。外部动作结果未知先查回执，不盲目重放。本包要求最低接续核对，不扩展复杂异常恢复、SLA、费用控制或角色专项体系。
正式发布由平台测试、灰度、全量，进行中运行保留冻结版本。
