# 宿主交接接口

版本：1.2.0。这里规定业务所需的输入和回传，不定义MA API或本地模拟事件引擎。实际绑定以references/ma-runtime.md和平台构建回执为准。

|环节|输入|真实输出要求|
|---|---|---|
|消息与身份|平台可信事件、发起人身份、正文及附件来源|唯一关联和实际读取记录；身份不能由正文指定|
|必经路由|routing_host.py的--input和--state|原版RoutingNode返回、投影和下一轮状态；只提方案|
|方案与确认|当前计划版本、发起人明确回应|确认记录及采用输入；未确认不分派|
|保存后分派|单接收方Context、包外Workspace位置|平台实际子Agent承接和调用关联|
|角色执行|work-item命令、输入及明确上游|真实标准返回、文件、摘要和必要检查|
|人工协作|同版人工任务及真实承接/提交|真实人工回传；未接通保持等待|
|交付与接续|当前产物、检查、交付与接受记录|真实可读位置及持久化证据；未知结果先查回执|

没有上述绑定时按缺项停住；包内不放伪造的宿主成功回执。
