# PM Context 组装与 Handoff

名称：PM Context 组装与 Handoff
适用范围：MA中PM及所需子智能体；本包合成业务场景
版本：1.2.0
负责人：Ada 项目维护方（模拟岗位；正式责任人待业务方指定）
状态：MA集群Demo运行规则；尚待真实平台构建与验收。

## 每次组装顺序
初次交接、影响变更和 s/h 整合前读取本规则。先定位有效确认单/plan 与一个工作项/接收方，再提取采用输入与真实读取状态，选择同一对话方相关且有效的 Memory，核对专业输入输出契约，组织来源与范围，检查必要材料和依赖，保存 Context 版本后交接。
Context 不是共用聊天摘要。用户要求、材料事实、专业判断、未决项分开；没有相关 Memory 可以为空，读到摘要不能宣称读过原件。旧周期结果不可作为本期事实。
## 接收方
t 获得本 Topic 工程与材料；g 获得局部动作、参数和上下游接口；validator 获得指定产物、版本、摘要和检查规则；s 只在所需自动结果及必要检查齐备后获得证据；h 获得完整业务问题、人工缺口、自动依赖和整合责任。
给出节点保存与返回要求、已授权目标和当前业务版本。接收、已承接、阶段完成和最终完成各有独立记录。已交接 Context 不因新消息或 Memory 修改而静默变更；有影响的变更确认后另存新版本。
