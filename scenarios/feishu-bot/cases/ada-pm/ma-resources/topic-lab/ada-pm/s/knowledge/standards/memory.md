# 两类 Memory 与采用规则

名称：两类 Memory 与采用规则
适用范围：MA中PM及所需子智能体；本包合成业务场景
版本：1.2.0
负责人：Ada 项目维护方（模拟岗位；正式责任人待业务方指定）
状态：MA集群Demo运行规则；尚待真实平台构建与验收。

## 归属与版本
ProjectMemoryDocument 存项目背景、口径、决定、历史结果及未决索引；PersonalMemoryDocument 存本人背景、明确长期偏好及结果索引。本次 Context、原始对话和工具结果不成为第三类长期记忆。本期不实现 Learning。
动态个人/项目 Memory 保存在相应 Workspace，Ada 可以保留生成依据并复制同版本给用户，只有一个当前有效版本；个人偏好不会因群聊而向项目公开。不把某个项目的事实装入员工全局资源包。
## 用户编辑
已确认采用按影响判断：作为有来源的新输入读取；普通背景可直接用于后续工作；影响已确认任务目标、范围或口径时先确认；多人实质冲突沿已有裁决。旧 Context 保持，不能静默覆盖。
明确“长期/以后”可形成有来源的偏好候选；一次性“本次”不升级长期偏好，推断不冒充本人确认。范围与敏感边界始终先于相关性。
## MA 适配
本次不配置员工共享的可写 memory store，避免把个人/项目作用域合并。Workspace Memory 按版本保存与回读；由MA实际提供的文件与持久化能力承载，其存储、隔离和跨会话可见性须在构建回执确认。需要新增员工级记忆库时另行逐库决策权限，默认只读；不以提示词承诺硬隔离或可回滚。
